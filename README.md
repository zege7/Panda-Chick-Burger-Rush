# Panda & Chick Burger Rush 🍔🐼🐣

A 3D cooking simulation game built with Unity and C#. This project was developed by expanding upon the foundation of CodeMonkey's cooking game tutorial, introducing custom mechanics, new recipes, and interactive obstacles.

## ✨ Custom Features & Additions
* **Character Selection:** Players can choose to play as a custom Panda or a Chick from the main menu.
* **French Fries Production Line:** Added a completely new recipe flow and order type. Players must fetch raw potatoes, chop them on the cutting board, and cook them on the stove before serving.
* **Interactive Mouse Obstacle:** Modified the base map to include roaming mice. If a player collides with a mouse, they drop their plated items, accompanied by a custom glass-breaking sound effect.
* **Level Modifications:** Altered the original map layout to accommodate the new gameplay loop and obstacles.

## 🛠️ Tech Stack
* **Engine:** Unity 3D
* **Language:** C#
* **Core Concepts:** Object-Oriented Programming (OOP), Event-Driven Architecture, ScriptableObjects
